# 第二次实验：模态调度与异构封装

本目录保存第二次实验的 M1-M4 成果：

- `polymorphic-scheduling/`：P4 数据面、P4Runtime 控制器、收发与解码脚本。
- `packet-summary.txt`：一入三出、序号、CRC、模态编号、外层协议和路径对应记录。
- `evidence/`：原始 pcap、控制器输出、回归日志和终端截图。
- `evidence/pcaps/`：正反向源网关出口及目的网关入口抓包。

完成范围是源网关复制、三模态封装和路径验证。M5 多数裁决与 M6 透明还原留到第三次实验。

本阶段对应 Git tag：`class2-multicast`。
